Демонстрація тегів форматування тексту в HTML

Ця сторінка створена для наочного відображення того, як працюють різні теги форматування тексту.

1. Фізичне та логічне форматування

Це звичайний текст для порівняння.

Цей текст є жирним (тег b), а цей — важливим / жирним (тег strong).

Цей текст виділено курсивом (тег i), а цей — є акцентованим / курсивом (тег em).

Цей текст вважається меншим за звичайний (тег small).

2. Редагування та виділення тексту

Ми можемо виділити текст маркером за допомогою тегу mark.

За допомогою тегів можна показати, що слово було видалено або додано нове в документ.

Також можна відобразити текст як закреслений (якщо він втратив актуальність).

3. Математичні та хімічні індекси

Верхній індекс (sup): Площа кімнати дорівнює 25 м2. Формула квадрата: a2 + b2 = c2.

Нижній індекс (sub): Формула води — H2}O. Формула глюкози — C6H12O6.

4. Комп'ютерний код та цитати

Для відображення назв клавіш використовують kbd: Натисніть Ctrl + S для збереження.

Короткий фрагмент коду в тексті: функція console.log() виводить дані в консоль.

Цитата всередині рядка: Розум без книги, як птах без крил.

Блочна цитата (blockquote):

"Логіка може привести вас від пункту А до пункту Б, а уява виведе вас куди завгодно."
— Альберт Ейнштейн
